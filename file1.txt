🧠 BACKEND ARCHITECTURE:

Layer 1: DATA INPUT
  └─ Buildings: {id, solar%, demand, income, type}

Layer 2: INTELLIGENCE (YOUR INNOVATION)
  ├─ Solar Suitability Engine
  │  ├─ Input: Building solar potential %
  │  ├─ Algorithm: (intrinsic × 50%) + (shading × 30%) + (efficiency × 20%)
  │  └─ Output: Solar Score (0-100)
  │
  ├─ Demand Estimation Engine
  │  ├─ Input: Building type + income level
  │  ├─ Algorithm: base_consumption × income_multiplier
  │  └─ Output: Daily Demand (kWh) + Priority Score
  │
  └─ Optimization Engine (CORE)
     ├─ Input: All building scores + weights
     ├─ Algorithm: 
     │  1. Composite score = (solar × solar_weight) + (equity × equity_weight)
     │  2. Sort all buildings by score
     │  3. Select top N as solar stations
     │  4. Calculate coverage & impact metrics
     └─ Output: Selected stations + metrics

Layer 3: VISUALIZATION
  └─ Frontend displays: Map + metrics + impact

Layer 4: IMPACT METRICS
  ├─ CO₂ avoided (metric tons/year)
  ├─ Peak load reduction (%)
  ├─ Diesel generators replaced (#)
  └─ Low-income beneficiaries (#)
